# Бот-модератор «Банка с нейронами»

Бот модерирует discussion group канала, проверяет новых участников, фильтрует ненормативную лексику и запускает голосования по жалобам на спам.

## Требования
- Python 3.11+
- PostgreSQL 13+
- PyTelegramBotAPI

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка окружения
Создайте файл `.env` (или используйте переменные окружения):
```
BOT_TOKEN=123456:ABCDEF
DISCUSSION_CHAT_ID=-1001234567890
DATABASE_URL=postgresql://user:pass@localhost:5432/dbname
SPAM_THRESHOLD=5
VOTE_TTL_SECONDS=600
```

> Убедитесь, что у бота выключен Privacy Mode и у него есть права удалять сообщения, ограничивать участников и закреплять сообщения.

## Запуск
```bash
python main.py
```
Бот использует `infinity_polling` и автоматически создаст нужные таблицы в базе данных.

## Команды
- `/export_verified` — выгружает CSV со списком верифицированных пользователей (только для администраторов чата).

## Тесты
```bash
pytest
```

## Структура проекта
- `main.py` — точка входа и регистрация хендлеров.
- `config.py` — загрузка настроек из `.env`.
- `db.py` — подключение к БД и операции с таблицами.
- `verification.py` — логика верификации новых участников.
- `moderation.py` — профанити-фильтр и удаление сообщений.
- `voting.py` — управление голосованиями за спам.
- `utils.py` — утилиты для нормализации текста и загрузки словаря.
- `profanity_words.txt` — словарь нежелательных слов (редактируйте под свои требования).
